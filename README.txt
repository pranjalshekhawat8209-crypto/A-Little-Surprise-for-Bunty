BUNTY FRIENDSHIP SURPRISE WEBSITE

This is a just-because best-friend surprise, not a birthday website.

Folder structure:
- index.html
- assets/css/style.css
- assets/js/script.js

HOW TO USE:
1. Extract the ZIP.
2. Open index.html in a browser to test it.
3. Personalize the message in index.html if you want.
4. Upload all files/folders to one GitHub repository, keeping the folder structure.
5. GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
6. Send Bunty the published GitHub Pages URL.

Google Fonts need an internet connection; the website otherwise works without external libraries.
